# Privacy Policy for Sahibinden AI Analiz

**Last Updated:** January 2026

Sahibinden AI Analiz ("we", "our", or "us") is committed to protecting your privacy. This Privacy Policy explains how our Chrome Extension handles data.

**1. Data Collection**
We do not collect, store, or share any personal identification information (PII) from users.
The extension only accesses the content of the active web page (specifically car listings on sahibinden.com) when you explicitly click the extension button.

**2. Data Usage**
The car listing data (text description, price, features, and public images) is sent to our processing server (n8n workflow) solely for the purpose of generating an AI-based analysis report via OpenAI API. This data is not stored permanently and is not used for any other purpose.

**3. Third-Party Services**
We use OpenAI API to analyze the car listings. Please refer to OpenAI's privacy policy for more information on how they handle data.

**4. Contact**
If you have any questions, please contact us via our GitHub repository.
